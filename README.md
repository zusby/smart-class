# Smart Class · Quiz Logical System

Quiz dal vivo: i giocatori rispondono dal telefono e il conduttore vede risposte, tempi e classifica in tempo reale.

- `index.html` – pagina dei giocatori (quella del QR code)
- `host.html` – schermo del conduttore (protetto da PIN)

Backend: Supabase (database e tempo reale). Le domande, le risposte giuste e il PIN stanno solo nel database: in questo repository c'è solo la chiave pubblica (publishable).
